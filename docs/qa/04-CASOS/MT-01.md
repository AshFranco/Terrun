# MT-01 — Dos puntos separados exactamente 1 km (Haversine)

**Resultado esperado (LLD §9):** 1000 m ± 0,5 m.

## Entrada

| Punto | lat | lon |
|---|---|---|
| A | 10,0 | −60,0 |
| B | 10,0 + Δlat | −60,0 |

`Δlat = 1000 / 6.371.008,8 × 180 / π = 0,008993216…°`

## Cálculo

Haversine: `a = sin²(Δφ/2) + cos φ₁ · cos φ₂ · sin²(Δλ/2)` y `d = 2R · asin(√a)`.

Sobre el meridiano, `Δλ = 0`, así que `a = sin²(Δφ/2)` y `d = 2R · asin(sin(Δφ/2)) = R · Δφ`.

`Δφ = 1000 / R` rad, entonces `d = R × 1000 / R = 1000 m`.

Segunda comprobación sobre el ecuador (`φ₁ = φ₂ = 0`, `cos 0 = 1`): `a = sin²(Δλ/2)` y, con `Δλ = 1000 / R` rad, también `d = 1000 m`.

## Resultado

1000 m en las dos direcciones (el error de redondeo es menor a 10⁻⁶ m), dentro de 1000 ± 0,5 m.
