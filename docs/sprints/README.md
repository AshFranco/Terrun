# Sprints

Un archivo por sprint (`S0.md`, `S1.md`, …), que crea Ashley al planificar y completa antes de la weekly. Es el histórico de lo que el equipo prometió y entregó cada semana.

## Plantilla

```markdown
# SN — Nombre del sprint (DD/MM – DD/MM)

## Objetivo
Una frase verificable.

## Compromiso
| ID | Historia | Responsable | Resultado |
|---|---|---|---|
| CTZ-XX | ... | ... | ✅ / ⛔ / ➡️ pasa a SN+1 |

## Resumen para la weekly (para el profesor, máx. 10 líneas)
- Avances:
- Impedimentos:
- Plan del próximo sprint:

## Métricas
- Historias hechas / comprometidas:
- Defectos abiertos (alta / media / baja):
- Hitos de control: cumplido / no cumplido (y plan B activado)

## Demo
Qué se mostró funcionando.

## Retrospectiva (cada dos sprints)
- Qué funcionó:
- Qué cambiar:
- Acción concreta y responsable:
```
